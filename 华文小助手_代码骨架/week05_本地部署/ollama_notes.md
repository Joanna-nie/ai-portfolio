# W5 Ollama 部署记录

## 1. 安装与拉取
- 安装方式：官网安装包（OllamaSetup.exe）
- 命令：`ollama run qwen2.5:0.5b`（注：因官方源网速过慢，实际采用魔搭社区下载 GGUF 离线包，并通过 `ollama create qwen2.5:0.5b -f Modelfile` 导入）

## 2. 我选的模型与理由
- 模型：qwen2.5:0.5b (Q4_K_M 量化版)
- 本机内存：16 GB
- 选择理由：参考"内存不足换更小量化档"的原则，优先保障电脑不卡顿。0.5b 模型体积仅 491MB，极轻量，首次跑通能建立手感，且响应速度极快，非常适合格式固定、人工可校验的批量任务。

## 3. 术语正名
让大模型进小内存靠的是 **量化 (Quantization)**；
**MCP** 另指"模型上下文协议"（第 10 周专讲），不要混用。

## 4. 隐私红线与脱敏操作
- **绝对不上云的数据**：学生真实作文、成绩单、未公开的教案、带有姓名/学号/联系方式的任何材料。
- **如果必须上云的脱敏步骤**：
  1. 删去所有学生姓名、学号；
  2. 删去学校名称、班级名称；
  3. 将具体分数改为“分数段”（如85分改为A档）；
  4. 确保文本中没有任何可以反向定位到具体个人的信息。

## 5. 排错记录
- **下载慢**：执行 `ollama run` 时官方拉取速度仅 21KB/s。解决：去国内魔搭社区下载 `.gguf` 离线文件，编写 `Modelfile` 后用 `ollama create` 命令秒速导入本地。
- **内存不足**：通过 `ollama ps` 观察，运行 0.5b 占用约 579MB。如果跑更大的模型卡顿，就换更小的量化档，或使用 `/bye` 退出释放内存。
- **服务未启动**：如果在 Python 里调用报错，需要在终端输入 `ollama serve` 启动服务，或者检查右下角羊驼图标是否在运行。
