# W6 双引擎封装边界测试记录

| 测试条件 | 实际走的引擎 | 耗时与答案质量点评 | 是否符合预期/怎么改的 |
| :--- | :--- | :--- | :--- |
| 1. 正常本地 (Ollama 开，prefer="local") | 本地 | 约 0.5s，本地 0.5b 模型给出了回答（内容有点胡编，但格式正确） | 符合预期。 |
| 2. 本地挂 → 切云端 (Ollama 关，prefer="local") | 云端 | 终端打印 `[本地失败，自动切换云端] HTTPConnectionPool...拒绝连接`。随后云端无缝接力，约 2-3 秒后给出了一道完整的 HSK4 阅读理解题（质量非常高）。 | **完美符合！** 回退代码生效，程序未崩溃，且云端质量明显更优。 |
| 3. 云端挂 → 切本地 (未配密钥/断网，prefer="api") | 本地 | 终端打印 `[云端失败，自动切换本地] 错误原因...` 随后本地秒答。 | 符合预期，没密钥也优雅降级。 |

**反思**：经过实测，涉及隐私或断网环境，应固定使用 `prefer="local"`，虽然质量一般但不泄密且稳定；如果遇到复杂的长文改写、出高质量题目，应固定 `prefer="api"`，云端大模型的质量明显更优。
