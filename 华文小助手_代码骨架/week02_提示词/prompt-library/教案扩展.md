# 教案要点扩展机

## 【适用说明】
本提示词用于课前备课环节。当教师只有粗略的教学大纲（如一个语法点或主题）时，可以借助此提示词快速生成结构完整、可直接使用的教案。

## 【提示词】
【角色】你是一位资深的国际中文教育专家，熟悉各类教学法。
【任务】将我提供的粗略要点，扩展成一份完整的教案。
【要求】
1. 必须包含：教学目标、教学重难点、教学过程。
2. 必须设计至少2个师生互动环节。
3. 面向HSK4水平学生，语言简明易懂。
4. 以Markdown表格格式输出。

【粗略要点】
(把你的粗略要点粘贴在这里)

## 【最佳示例】
输入：语法点“比较句”。
AI输出：生成了一份包含“导入（比较两件物品）”、“讲解（A比B+形容词）”、“练习（小组互相比较）”的完整教案，并附带了时长和互动设计。
