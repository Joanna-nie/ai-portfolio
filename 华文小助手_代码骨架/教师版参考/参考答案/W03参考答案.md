# W03　Python 速成（AI 结对编程） · 参考答案

## 一、目标达成证据（学生应交出什么）
vocab_tool.py 能读 CSV、按等级筛选、输出练习题；有 AI 辅助编程实录。

## 二、参考实现要点
csv.DictReader 读表 → 列表推导筛选 → 写文件；注意 encoding="utf-8"。

## 三、预期输出示例
```
HSK4 词汇 4 个，词性分布：{...}；已生成 练习.txt
```

## 四、评分要点（三档）
达标：脚本可运行、练习题文件有内容；良好：实录含"AI 初版 vs 我的修改"；优秀：自己加了词性统计/分组等扩展功能。

## 五、常见错误与排查
CSV 路径写死导致换机器报错；忘记 encoding 导致中文乱码；直接粘贴 AI 代码不读。

## 六、可给学生的提示话术（不给答案，只给方向）
"报错先看最后一行，Traceback 里带文件名和行号，那一行就是问题所在。"
