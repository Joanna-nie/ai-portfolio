# W02　提示词即资产 · 参考答案

## 一、目标达成证据（学生应交出什么）
prompt-library/ 有 ≥6 个模板，每个含四件套；有 ≥3 轮迭代记录。

## 二、参考实现要点
模板必须含：角色 / 任务 / 要求（格式·受众·约束）/ 示例；结构化输出用表格或 JSON。

## 三、预期输出示例
```
好提示应让输出从"泛泛而谈"变成"可直接用于课堂的表格化题目"。
```

## 四、评分要点（三档）
达标：≥6 模板且结构完整；良好：迭代记录说明了"改了什么、为什么变好"；优秀：模板限定到自己学科轨（如明确 HSK 等级约束）。

## 五、常见错误与排查
把提示词写成一句话需求；只留最终版没有迭代过程；模板通用化、看不出学科。

## 六、可给学生的提示话术（不给答案，只给方向）
"试试在提示词里加一句『以 Markdown 表格输出』，看看输出变化大不大。"
