# W04　API 问答机器人 · 参考答案

## 一、目标达成证据（学生应交出什么）
week4_api_bot.py 能调通并打印；3 个学科问题示例；密钥零泄露。

## 二、参考实现要点
os.getenv 读密钥；openai.OpenAI(base_url=..., api_key=...)；chat.completions.create。

## 三、预期输出示例
```
Q: 把字句的教学难点有哪些
A: 把字句的难点主要在……(答案由模型生成)
```

## 四、评分要点（三档）
达标：能跑通并追加日志；良好：有 temperature/max_tokens 体验记录与费用估算；优秀：错误信息友好（缺密钥/超时各有提示）。

## 五、常见错误与排查
把密钥硬编码进代码；忘记 .gitignore 导致 .env 被提交；base_url 与 model 不匹配。

## 六、可给学生的提示话术（不给答案，只给方向）
"先确认 import os 之后 os.getenv("DEEPSEEK_API_KEY") 打印出来不是 None。"
