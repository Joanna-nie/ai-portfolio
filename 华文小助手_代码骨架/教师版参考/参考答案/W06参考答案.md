# W06　双引擎封装 · 参考答案

## 一、目标达成证据（学生应交出什么）
llm.py 有 LocalEngine / APIEngine / LLM，本地失败能自动切云端且不崩溃。

## 二、参考实现要点
统一 ask(prompt) 接口；try/except 包住本地调用，异常时回落云端。

## 三、预期输出示例
```
[本地失败，自动切换云端] ConnectionError...（随后正常输出答案）
```

## 四、评分要点（三档）
达标：两个引擎都能调、异常有提示；良好：prefer 参数可切换；优秀：说明了隐私任务走本地、复杂任务走云端的判断依据。

## 五、常见错误与排查
except 里什么都不做导致静默失败；把异常吞掉后返回空字符串；类名与后续周 import 不一致。

## 六、可给学生的提示话术（不给答案，只给方向）
"把 Ollama 关掉再跑一次，看看它会不会自动切到云端——这就是兜底。"
