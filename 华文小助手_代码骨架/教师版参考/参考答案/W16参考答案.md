# W16　路演与收官 · 参考答案

## 一、目标达成证据（学生应交出什么）
Release v2.0；1000 字报告含 AI 使用披露段；6 件交付物 ≥4 件可运行。

## 二、参考实现要点
提交前 git status / git log --all -- .env 复查密钥。

## 三、预期输出示例
```
git status 无 .env；报告五段齐全（流程/学科价值/技术/伦理/披露）。
```

## 四、评分要点（三档）
达标：路演完成 + 报告齐全；良好：披露段写清了 AI 用在哪些环节；优秀：伦理复盘覆盖密钥—幻觉—注入—隐私四条线。

## 五、常见错误与排查
报告缺 AI 使用披露段（红线）；.env 曾误提交未清理；交付物少于 4 件。

## 六、可给学生的提示话术（不给答案，只给方向）
"提交前一定跑一遍 git status 和 git log --all -- .env，这是红线。"
