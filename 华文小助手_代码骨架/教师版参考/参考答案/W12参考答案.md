# W12　低代码对比与项目二 · 参考答案

## 一、目标达成证据（学生应交出什么）
学科教学智能体（代码版或平台版）可演示；300 字选型反思。

## 二、参考实现要点
系统提示词定义工作流与约束；平台侧用知识库 + 工作流节点。

## 三、预期输出示例
```
同一份学生答案 → 输出『优点 / 问题 / 修改建议』三段式反馈。
```

## 四、评分要点（三档）
达标：可演示；良好：选型反思有对比维度；优秀：论证结合场景（要可控/私有化选代码，要快出原型选平台）。

## 五、常见错误与排查
选型只说"平台简单"；反馈没有分三段；忘了标注"需教师复核"。

## 六、可给学生的提示话术（不给答案，只给方向）
"你评一下：灵活性、可控性、上手速度，各打几分？再决定用哪条路。"
