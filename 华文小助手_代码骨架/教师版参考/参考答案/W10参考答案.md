## 四、评分要点（三档）
达标：自定义工具可调用；良好：配置记录含截图与字段名；优秀：辨析准确——Function Calling 是模型侧机制，MCP 是工具侧协议。

## 五、常见错误与排查
把 MCP 说成"模型压缩"；客户端配置 JSON 字段名写错；工具函数没有类型注解。
**2026-09 实测新增**：mcp 2.x 起 `FastMCP` 已改名 `MCPServer`，`from mcp.server.fastmcp import FastMCP`
会直接 ImportError —— 骨架已改成版本自适应（1.x/2.x 都跑得通），若学生自己照旧教程写会踩这个坑。
