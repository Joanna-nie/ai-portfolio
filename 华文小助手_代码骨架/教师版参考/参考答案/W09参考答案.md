# W09　工具调用循环 · 参考答案

## 一、目标达成证据（学生应交出什么）
tool_agent.py 能自主决定调哪个工具；3 条调用轨迹记录。

## 二、参考实现要点
模型输出 JSON → json.loads → TOOLS[name](*args) → 结果回喂再生成。

## 三、预期输出示例
```
问"把字是 HSK 几级？现在几点？"→ 分别调用 hsk_level 与 get_time 后作答。
```

## 四、评分要点（三档）
达标：3 工具可调、能走通一轮；良好：轨迹记录清晰；优秀：能处理模型输出不是 JSON 的情况（try/except 兜底直接返回）。

## 五、常见错误与排查
模型输出带 markdown 代码围栏导致 json.loads 失败；工具名拼错；忘了回喂结果。

## 六、可给学生的提示话术（不给答案，只给方向）
"如果模型输出了 ```json 这样的围栏，先 strip 掉再解析。"
