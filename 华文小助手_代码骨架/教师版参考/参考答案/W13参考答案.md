# W13　学科教学小游戏 · 参考答案

## 一、目标达成证据（学生应交出什么）
subject_game.html 浏览器双击可玩；≥3 处手工修改有说明；3 轮迭代记录。

## 二、参考实现要点
HTML+CSS+JS 一体；判定首字 == 上一个成语尾字；加分与提示。

## 三、预期输出示例
```
输入"山穷水尽"→ 提示首字应为「山」；接对后得分 +10。
```

## 四、评分要点（三档）
达标：能玩；良好：有反馈感（对错提示/计分）；优秀：有氛围（音效/动画/汉字卡片）+ 内容为中华语言文化。

## 五、常见错误与排查
把整个游戏逻辑交给 AI 后完全没读；成语库太小导致很快无解；没记录迭代。

## 六、可给学生的提示话术（不给答案，只给方向）
"第一轮先让它『能玩』，别一上来就要好看——下一轮再加反馈。"
