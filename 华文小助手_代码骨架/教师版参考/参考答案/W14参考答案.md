# W14　多模态接入 · 参考答案

## 一、目标达成证据（学生应交出什么）
multimodal_feature.md 有图像 1 次 + 语音 1 次接入记录，含学科用途。

## 二、参考实现要点
图像：base64 + image_url content；语音：audio.transcriptions.create(model="whisper-1")。

## 三、预期输出示例
```
图像：生成看图写话题 + 评分要点；语音：转写文本 + 流利度点评。
```

## 四、评分要点（三档）
达标：两类各 1 次成功；良好：说明了教育用途；优秀：讨论了图像/语音上传的合规边界（脱敏、授权）。

## 五、常见错误与排查
图片路径错/未放图；API 不支持该多模态模型名；把真实学生录音直接上传。

## 六、可给学生的提示话术（不给答案，只给方向）
"想一想：这段录音里有学生真实姓名和班级，能直接传吗？"
