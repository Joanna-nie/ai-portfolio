# W07　RAG 知识库问答 · 参考答案

## 一、目标达成证据（学生应交出什么）
rag_qa.py 可运行；幻觉对照表 ≥5 组，有 RAG 的答案能给出来源。

## 二、参考实现要点
TextLoader → RecursiveCharacterTextSplitter(500/50) → OllamaEmbeddings → Chroma → retriever。

## 三、预期输出示例
```
【检索片段】……（命中等级标准相关段落）；有 RAG 答案显著优于无 RAG。
```

## 四、评分要点（三档）
达标：能检索并作答、对照表 ≥5 组；良好：有 RAG 答案能引用资料；优秀：指出 RAG 边界（检索不到照样答不好）。

## 五、常见错误与排查
没先 ollama pull nomic-embed-text；chunk 过大/过小影响检索；忘了 persist_directory。

## 六、可给学生的提示话术（不给答案，只给方向）
"同一个问题，先直接问模型、再走 RAG，把两次回答贴在一起对比。"
