# W05　本地部署与对比 · 参考答案

## 一、目标达成证据（学生应交出什么）
ollama_notes.md 含安装步骤、选型理由、本地 vs 云端对比表（≥5 问）。

## 二、参考实现要点
ollama pull / list / ps；本地 http://localhost:11434/api/chat。

## 三、预期输出示例
```
ollama list 能看到 qwen2.5:0.5b；ollama ps 显示占用。
```

## 四、评分要点（三档）
达标：本地能对话、对比表 ≥5 问；良好：选型理由结合了本机内存；优秀：说清了"量化 ≠ MCP"及什么时候该上云/该本地。

## 五、常见错误与排查
内存不足却强行拉大模型；把 MCP 当成"模型压缩"；对比表只写快慢不写质量与隐私。

## 六、可给学生的提示话术（不给答案，只给方向）
"你本机内存多少 GB？对照一下再选 0.5b 还是 1.5b。"
