# 教师版参考答案与参考实现（勿提前发给学生）

本目录面向**教师与助教**，用于批改与巡场答疑。

## 使用建议
- **不要**在学生提交前把本目录发给学生——骨架包的设计意图是让学生自己实现。
- 巡场答疑时优先给"方向性提示"（每份答案里都有"可给学生的提示话术"），
  学生确实卡住 10 分钟以上再给关键片段。
- 参考答案分三档给出：达标 / 良好 / 优秀，便于快速给分。

## 目录
- `参考答案/W01–W16参考答案.md` —— 每周：达成证据 / 参考实现要点 / 预期输出 / 评分要点 / 常见错误 / 提示话术
- `参考代码/` —— 关键周的**增强版**参考实现（比骨架更完整，仅供教师对照）
- `端到端自检_e2e.py` —— **开学前 / 镜像封装后必跑**的教师自检脚本（见下）

## v3 复核后的对齐约定（重要）
- `参考代码/` 下文件的**函数签名已与学生骨架逐一对齐**，可直接覆盖到对应 week 目录做演示：
  - `llm_参考.py` → `LLM().ask(prompt, prefer=...)`（额外支持 history / retries / spent）
  - `rag_qa_参考.py` → `retrieve(question)` 同名同签名，另有 `rag_qa()` 返回 (答案, 来源)
  - `planner_agent_参考.py` → `planner_agent(lesson, retriever=None, auto_confirm=False)`
  - `tool_agent_参考.py` → `run(user_msg, max_calls=2)`，安全计算用白名单 AST（非 eval）
- 参考代码位于 `教师版参考/参考代码/`，比周目录深一层，因此定位代码包根目录时用
  **三次** `os.path.dirname`；学生周目录用两次。
- 若课堂演示需要临时把参考代码拷进 week 目录，拷完请恢复骨架版本，避免学生直接抄。

## 端到端自检（教师机专用，建议在开学前跑一次）

```bash
python 教师版参考/端到端自检_e2e.py
```

与学生用的 `setup_check.py`（只看"装没装"）不同，这个脚本是**真的跑一遍** W4—W15：
本地模型推理、双引擎切换、RAG 建库与检索、助手问答、工具调用与越权拒绝、
OpenAI SDK 链路、MCP 协议层调用、备课智能体、多模态缺密钥降级、Streamlit 启动与健康检查。

- 输出三档：`[通过]` / `[跳过]`（本机不具备条件，如 Ollama 未启动，不会误报失败）/ `[失败]`
- 云端密钥非必需，不配也能跑完全部本地链路
- 脚本会在代码包根目录生成 `chroma_db/`，**打包分发给学生前请删除**
- 依赖版本会漂移（本次复核就撞上 `mcp` 升到 2.2.0 导致旧写法 ImportError），
  建议每学期开课前跑一次，把"装完就用"变成"验完再用"

## 评分通用原则
1. 能跑 > 好看：先确认功能可运行，再看代码质量
2. 迭代记录比最终版更重要（这是素养目标3的证据）
3. 密钥零泄露是**一票否决**红线
4. 学科贴合度：产物必须真的能用在国际中文教学场景
