# 第4周 参数体验记录

| 参数 | 我填的值 | 观察到的现象 |
| :--- | :--- | :--- |
| temperature = 0.0 | 0.0 | 多次运行同一个问题，回答几乎一字不差，非常稳定，确定性强，可复现。 |
| temperature = 1.5 | 1.5 | 每次回答都不一样，内容非常发散，甚至出现了一些不太通顺或天马行空的句子。 |
| max_tokens = 15 | 15 | 回答被硬截断，只输出了半句话，如“把字句是汉语中一种用介词...”，后面直接没了。 |
| max_tokens = 800 | 800 | 回答完整，能输出长段落，能把问题讲清楚。 |

**参数作用总结：**
- `temperature` 控制“发散度”。值越小（如0.0），回答越保守、确定；值越大（如1.5），回答越随机、有创造力，但也容易跑偏。
- `max_tokens` 控制“长度”。值太小（如15），回答会被硬生生切断；值适中（如800），可以输出完整的段落。
